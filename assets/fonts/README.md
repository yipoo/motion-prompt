# Noto Sans SC

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf
License: SIL Open Font License 1.1, see OFL.txt.

Self-hosted variable WOFF2, retaining U+0000–00FF, U+2000–206F, U+2190–21FF, U+2460–24FF, U+3000–303F, U+3400–9FFF and U+FF00–FFEF. Covers basic Chinese ideographs and common interface punctuation. No external requests or device-installed Chinese fonts are needed. FontTools converted the official font with layout features preserved and hints removed.
