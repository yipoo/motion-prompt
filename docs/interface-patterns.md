## 分工与分级

motion 收录可组合的运动机制：时序、轨迹、缓动、循环、反馈。ADP 收录有任务语义、完整状态与接入事件的 Agent 组件或区块。已有磁吸、涟漪、数字滚动等条目保持原样，不重复增加。

本批基础、用途单一的机制为 Free；多阶段状态、联动或速度映射机制为 Pro。原有 #001–#312 的访问等级不变。当前共 324 项、14 包，198 Free / 126 Pro。以条目 `tier` 为正式来源，不再把所有编号大于 192 的新增项一律判为 Pro。

## 原创与访问边界

代码、双语规格和演示独立编写。原仓库 MIT 授权与署名保持不变。Pro 是托管规格、prompt 和便捷导出服务的访问等级，不能撤回已公开版本的 MIT 权利；预览渲染代码依然公开。

混合等级素材包的共享辅助代码可公开，但不包含 Pro 条目的独立实现段。托管构建按 `tier` 删除 Pro 文本导出，将完整内容放入受现有 Pro 身份检查保护的服务资源。前端、CLI、构建和服务可用 ID 清单保持一致。
