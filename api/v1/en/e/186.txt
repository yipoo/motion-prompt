Motion Prompt #186 · Morph cut
Two takes of the same person are joined by smoothly interpolating position and pose, so nothing jumps as in a jump cut.

- Take 1 (0–2.0 s): fixed camera (height 1.45 m); the person stands 0.4 m left, 3.3 m away, arms and legs at -0.45 rad. Take 2 (from 2.45 s): 0.35 m right, +0.55 rad. Both sway slightly by 0.12·sin(t×3) rad
- Morph (2.0–2.45 s, 0.45 s): the position is interpolated with a quadratic ease-in-out (about cubic-bezier(0.45,0,0.55,1)), and the two poses are drawn at the same interpolated position and cross-faded
- Only during the morph a blur of sin(q×π)×2.2 px is applied to the whole frame to soften the join (#041 Jump cut lets the position jump)
- Bottom strip: take 1 (grey), morph (blue, narrow), take 2 (grey) with a playhead
- Return: cross-fade back to the start of take 1 over the last 0.5 s; top-right readout shows "TAKE 1" → "MORPH" → "TAKE 2"

  // @element 18
    CELLS[17] = shot((k, w, h, u) => {
    const T0 = 2, T1 = 2.45, r = P(u, CYC - RESET, CYC);
    const draw = (kk, t) => {
      const q = eIOs(P(t, T0, T1));
      const pose = (k2, m) => world(k2, w, h, cam({
        y: 1.45,
        z: 0
      }), {
        person: {
          x: lerp(-.4, .35, q),
          z: 3.3,
          walk: (m ? .55 : -.45) + .12 * Math.sin(t * 3)
        },
        trees: true,
        buildings: true
      });
      const bl = Math.sin(q * Math.PI) * 2.2;
      kk.save();
      kk.filter = bl > .05 ? `blur(${bl.toFixed(2)}px)` : "none";
      blend(kk, k2 => pose(k2, false), k2 => pose(k2, true), q);
      kk.restore();
      strip(kk, w, h, [ [ 0, T0, MotionLocale.text("copy_053"), C.g2 ], [ T0, T1, "", C.blue ], [ T1, CYC, MotionLocale.text("copy_054"), C.g2 ] ], t);
    };
    blend(k, kk => draw(kk, u), kk => draw(kk, 0), eIOs(r));
    return r > .5 || u < T0 ? MotionLocale.text("TAKE 1") : u < T1 ? MotionLocale.text("MORPH") : MotionLocale.text("TAKE 2");
  });
