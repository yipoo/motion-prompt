Motion Prompt #251 · Checker reveal
Alternating square masks grow from their centres to reveal a landscape.

- 539×208 px Canvas 2D card; 4.8 s deterministic seamless loop. Unless stated otherwise q=(1−cos(2πt/4.8))/2.
- Use a 10×4 grid of 38×37 px cells over the image.
- Cell width and height scale with q; alternating cells have a 0.08-cycle phase offset.

Canvas: 539×208; cycle: 4.8s.

Set document.documentElement.lang to en. Load Motion Sans before drawing.

  // @element 11
  CELLS[10]=wrap((k,p)=>{k.save();k.beginPath();for(let y=0;y<4;y++)for(let x=0;x<10;x++){let q=wave(p+(x+y)%2*.08);k.rect(80+x*38+19*(1-q),30+y*37+18.5*(1-q),38*q,37*q);}k.clip();scene(k);k.restore();});
