Motion Prompt #237 · Matrix propagation
Matrix cells activate along a diagonal wave, then pulse in color.

- The 5×11 matrix uses 25×19 px cells with 36 px horizontal and 28 px vertical steps.
- Cell (r,c) activates over 0.2 + .13(r+c) to 0.6 + .13(r+c) s; color then pulses with sin(4u−r−c).
- Canvas 539×208, cycle 4.8 s; all content fades in over 0–0.2 s and out over 4.5–4.8 s, leaving the same background at both ends.

Canvas: 539×208; cycle: 4.8s.
