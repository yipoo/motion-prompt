Motion Prompt #303 · Pointer sparks
Twenty-two sparks radiate from the pointer.

- Base canvas 539 × 208; 4.8-second loop with phase a = t / 4.8 × 2π. Fullscreen mode lays out against actual width and height.
- Twenty-two sparks radiate from the pointer; drawn with Canvas 2D using #a8c9ff, #ddf98b, #c7a6ff and #ffb896 on #080e21.
- The gallery simulates the pointer on a deterministic sine path. Interactive mode normalizes pointermove to 0–1 and passes it to render(index,ctx,width,height,time,pointer); leaving restores the automatic path.
- Use bundled Motion Sans and switch demo copy with Chinese/English. A sitewide overlay uses pointer-events:none to preserve page interaction. Reduced motion shows a static keyframe.

Canvas: 539×208; cycle: 4.8s.
