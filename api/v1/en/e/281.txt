Motion Prompt #281 · Particle attractor
A rotating cloud spirals inward toward a glowing core and expands again.

- One hundred particles use q = 2.39996i+a and base radius 24+177√(i/99), vertically compressed to 40%.
- Contraction p = 0.5−0.5 cos(a) multiplies every radius by 1−0.83p, so the cloud contracts to 17% at mid-cycle.
- Particle radii cycle through 1.5,2,2.5 px; a gold core grows from radius 8 to 12 px as the cloud gathers.

Canvas: 539×208; cycle: 4.8s.

  // @element 17
  CELLS[16] = scene('PARTICLE ATTRACTOR', '粒子吸引', a => {
    const contraction=.5-.5*Math.cos(a);for(let i=0;i<100;i++){const q=i*2.39996+a, r=(24+Math.sqrt(i/99)*177)*(1-.83*contraction);const x=269+Math.cos(q)*r,y=113+Math.sin(q)*r*.4;dot(x,y,1.5+i%3*.5,i%3?C.blue:C.mint);}glow(269,113,8+4*contraction,C.gold);ellipse(269,113,194,78,C.grid);
  });
