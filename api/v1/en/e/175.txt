Motion Prompt #175 · Locked-off shot
A person crosses in front of a tripod-fixed camera and a car passes behind; the camera does not move by a pixel.

- Camera: completely fixed (height 1.4 m, facing forward, focal length 330 px); only the subjects move
- Subject: a person crosses left to right at constant speed 6.5 m ahead (x = -6.2 m → +6.2 m in 4.7 s); legs and arms swing by sin(u×7)×0.42 rad
- A grey car crosses right to left 15 m away (x = +16 m → -16 m in 4.7 s)
- Both start and end outside the frame, so it loops seamlessly every 4.7 s
- A grey tripod mark at bottom left; top-right readout shows "LOCKED" (#040 Freeze frame stops the footage time; here time runs and only the camera is still)

Canvas: 539×208; cycle: 9.4s.

  // @element 07
    CELLS[6] = shot((k, w, h, u) => {
    const q = u / CYC;
    world(k, w, h, cam({
      y: 1.4
    }), {
      person: {
        x: lerp(-6.2, 6.2, q),
        z: 6.5,
        walk: u * 7
      },
      extra: [ [ lerp(16, -16, q), 0, 15, kk => {
        kk.fillStyle = C.g4;
        rr(kk, -1.9, .35, 3.8, .75, .25);
        kk.fill();
        rr(kk, -1.1, .95, 2.1, .62, .28);
        kk.fill();
        kk.fillStyle = C.ink;
        [ -1.15, 1.15 ].forEach(x => {
          kk.beginPath();
          kk.arc(x, .34, .34, 0, 7);
          kk.fill();
        });
      } ] ],
      after: kk => {
        kk.strokeStyle = C.g4;
        kk.lineWidth = 2.2;
        kk.lineCap = "round";
        const x = -w / 2 + 38, y = h / 2 - 20;
        kk.beginPath();
        kk.moveTo(x, y - 30);
        kk.lineTo(x - 12, y);
        kk.moveTo(x, y - 30);
        kk.lineTo(x + 12, y);
        kk.moveTo(x, y - 30);
        kk.lineTo(x, y - 2);
        kk.stroke();
        kk.fillStyle = C.g4;
        rr(kk, x - 9, y - 42, 18, 12, 3);
        kk.fill();
      }
    });
    return MotionLocale.text("LOCKED");
  });
