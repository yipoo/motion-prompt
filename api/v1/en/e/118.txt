Motion Prompt #118 · Film grain
Fine grain appears over the whole of the same landscape and the colours lean slightly towards a warm cream.

- Scene 3: a bust on the left (head centre x 140, y 82, radius 28 px) and hills, a house, trees and the sun (x 432, y 54, radius 15 px) on the right.
- Grain: 2,600 squares (fixed seed), 0.8–1.7 px; 55% dark #3A3530, 45% white
- Grain opacity: 16–38% × the effect; the grain does not move (no flicker)
- Colour: every colour moves 16% towards #F2DDBE
- Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))

Canvas: 539×208; cycle: 5s.

  // @element 22
    CELLS[21] = cell((k, u) => {
    const a = env(u);
    const FILM = mapPal(BASE, c => mixc(c, "#F2DDBE", .16));
    const p = pal(BASE, FILM, a);
    const G = once("grain", () => {
      const r = rng(22), o = [];
      for (let i = 0; i < 2600; i++) o.push([ r() * CW, r() * CH, .8 + r() * .9, r() < .55 ? 0 : 1, .16 + r() * .22 ]);
      return o;
    });
    const grain = kk => {
      kk.save();
      for (const [x, y, s, d, al] of G) {
        kk.globalAlpha = al * a;
        kk.fillStyle = d ? "#FFFFFF" : "#3A3530";
        kk.fillRect(x, y, s, s);
      }
      kk.restore();
    };
    stageLand(k, p);
    grain(k);
  });
