Motion Prompt #173 · Stabilized tracking
The camera glides forward after a walking person with only a slow, gentle sway and no jitter, unlike handheld.

- Camera: moves forward at a constant 1.7 m/s (8 m per 4.7 s); height 1.45 m, pitch -0.02 rad; no easing
- Sway: height ±3.5 cm (2 cycles per 4.7 s), sideways ±5 cm (1 cycle), yaw ±0.012 rad, roll ±0.006 rad, all sine waves with integer periods, slow and wide (#034 Handheld is fast and irregular)
- Subject: a person walks 5 m ahead of the camera at the same speed; legs and arms take 5 strides per 4.7 s
- Trees: 3.6 m tall at x = -5 m and 3.2 m tall at x = +5 m, every 8 m (the two rows offset by 4 m); the mountains and sun move with the camera
- 8 m is a multiple of the grid (2 m) and tree (8 m) spacing, so it loops seamlessly every 4.7 s; top-right readout shows "STABILIZED"

Canvas: 539×208; cycle: 9.4s.

  // @element 05
    CELLS[4] = shot((k, w, h, u) => {
    const v = 8 / CYC, z = u * v, T = u * 2 * Math.PI / CYC;
    const c = cam({
      z: z,
      y: 1.45 + .035 * Math.sin(T * 2),
      x: .05 * Math.sin(T),
      yaw: .012 * Math.sin(T + 1),
      roll: .006 * Math.sin(T * 2 + .5),
      pitch: -.02
    });
    const ex = [], L = 8, base = Math.floor(z / L) * L;
    for (let i = 0; i < 10; i++) {
      const zz = base + i * L;
      ex.push([ -5, 0, zz + 2, (kk, s) => tree(kk, s, 3.6) ]);
      ex.push([ 5, 0, zz + 6, (kk, s) => tree(kk, s, 3.2, C.blueXL) ]);
    }
    world(k, w, h, c, {
      buildings: false,
      trees: false,
      extra: ex,
      mtnZ: z,
      sun: [ 30, 30, z + 170 ],
      gridX: 20,
      person: {
        z: z + 5,
        walk: T * 5
      }
    });
    return MotionLocale.text("STABILIZED");
  });
