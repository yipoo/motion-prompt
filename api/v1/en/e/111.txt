Motion Prompt #111 · Chromatic aberration
The street scene is split into red, green and blue and the three are laid back together at slightly different sizes, so red and cyan fringes appear on the edges of the person, buildings and lamps, larger towards the sides.

- Scene 2: a street corner; buildings, trees and street lamps (x 114, 292, 494) behind a road at y 132–162; the person stands front left (feet at x 176, y 200, 124 px tall).
- Split: the image is multiplied by red #FF0000, green #00FF00 and blue #0000FF into three copies and added back together over black
- Scale about the centre: red 1 + 2s, green 1 + s, blue 1, with s = 0 → 0.02
- Offset: red and blue end up about 11 px apart at the left and right edges, 0 at the centre
- Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))

Canvas: 539×208; cycle: 5s.

  // @element 15
    CELLS[14] = cell((k, u) => {
    const a = env(u), s = .02 * a, cx = CW / 2, cy = CH / 2;
    if (s < 5e-4) {
      stageStreet(k, BASE);
      return;
    }
    const [S, ks] = layer("ca");
    stageStreet(ks, BASE);
    k.fillStyle = "#000000";
    k.fillRect(0, 0, CW, CH);
    for (const [col, sc] of [ [ "#FF0000", 1 + 2 * s ], [ "#00FF00", 1 + s ], [ "#0000FF", 1 ] ]) {
      const [L, kl] = layer("ca-" + col);
      kl.drawImage(S, 0, 0);
      kl.globalCompositeOperation = "multiply";
      kl.fillStyle = col;
      kl.fillRect(0, 0, CW, CH);
      kl.globalCompositeOperation = "source-over";
      k.save();
      k.globalCompositeOperation = "lighter";
      k.translate(cx, cy);
      k.scale(sc, sc);
      k.translate(-cx, -cy);
      k.drawImage(L, 0, 0);
      k.restore();
    }
  });
