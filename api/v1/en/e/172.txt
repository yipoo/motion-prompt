Motion Prompt #172 · Long take
One continuous shot follows a walking person with no cut; the bar at the bottom stays a single unbroken strip.

- Join: none; for 4.2 s one shot keeps following the person (#041 Jump cut splits it into five)
- Subject: a person walks at constant speed from front left (x = -3.4 m, 5.2 m deep) to back right (x = 2.8 m, 9.6 m deep); legs and arms swing by sin(t×7)×0.42 rad
- Camera: trucks right 0 m → 1.4 m after the person while turning, yaw = atan2(person x - camera x, depth)×0.8; height 1.4 m
- Bottom strip: one blue bar labelled "One take · no cuts" (one shot, no cut) with a playhead, showing there is no break
- Return: stops at 4.2 s, then cross-fades back to the start over the last 0.5 s (one pass = 4.7 s)
- Top-right readout shows the elapsed time (NO CUT 0.0s → 4.2s)

  // @element 04
    CELLS[3] = shot((k, w, h, u) => {
    const uu = Math.min(u, CYC - RESET);
    const draw = (kk, t) => {
      const p = t / (CYC - RESET);
      const x = lerp(-3.4, 2.8, p), z = lerp(5.2, 9.6, p), cx = lerp(0, 1.4, p);
      world(kk, w, h, cam({
        x: cx,
        y: 1.4,
        yaw: Math.atan2(x - cx, z) * .8
      }), {
        person: {
          x: x,
          z: z,
          walk: t * 7
        },
        fg: [ [ -2.6, 3.4 ], [ 3.6, 4.6, "rock" ] ]
      });
      strip(kk, w, h, [ [ 0, CYC, MotionLocale.text("copy_055"), C.blue ] ], t);
    };
    const r = P(u, CYC - RESET, CYC);
    blend(k, kk => draw(kk, uu), kk => draw(kk, 0), eIOs(r));
    return `NO CUT ${(r > .5 ? 0 : uu).toFixed(1)}s`;
  });
