Motion Prompt #079 · Scroll progress bar
As the article is read a bit at a time, the line along the top grows from the left and reaches the far end at the bottom of the page.

- The article scrolls 0→430 px in four 110 px steps, each moving for 0.45 s then pausing 0.4 s (cubic ease-in-out).
- It returns 430→0 at 3.75–4.55 s.
- A 6 px bar along the top of the viewport: light grey track, orange fill.
- Fill width = 511 px × scroll / 430, the scroll fraction itself (the same as CSS animation-timeline: scroll()).

Canvas: 539×208; cycle: 4.8s.

Set document.documentElement.lang to en. Load Motion Sans before drawing.
Reference source: studio/packs/lp.js

  // @element 07
    CELLS[6] = (k, w, h, u) => {
    frame(k);
    const MAX = 430;
    const y = steps([ [ .3, 0 ], [ .75, 110 ], [ 1.15, 110 ], [ 1.6, 220 ], [ 2, 220 ], [ 2.45, 330 ], [ 2.85, 330 ], [ 3.3, MAX ], [ 3.75, MAX ], [ 4.55, 0 ] ], u);
    view(k, () => {
      k.save();
      k.translate(0, -y);
      txt(k, MotionLocale.text("copy_146"), 70, 44, `800 20px ${FONT}`, C.ink);
      bars(k, 70, 56, 120, 1, C.faint, 5);
      pic(k, 70, 74, 371, 112, 0, 8);
      for (let b = 0; b < 4; b++) {
        const y0 = 204 + b * 82;
        k.fillStyle = C.ink;
        rr(k, 70, y0, 140, 9, 4.5);
        k.fill();
        bars(k, 70, y0 + 22, 371, 4, C.faint, 6, 12);
      }
      k.restore();
      k.fillStyle = C.faint;
      k.fillRect(0, 0, VW, 6);
      k.fillStyle = C.acc;
      k.fillRect(0, 0, VW * (y / MAX), 6);
      sbar(k, y / MAX, .3);
    });
  };
