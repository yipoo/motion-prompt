Motion Prompt #182 · Deep focus
From the flower in front to the person and buildings behind, everything comes into sharp focus at the same time.

- Camera: position, direction and focal length all fixed (height 1.1 m); only the blur amounts change
- Blur: the foreground flower (0.75 m left, 2 m away) goes 5 px → 0 px and the background (person 0.9 m right, 9 m away; buildings; mountains) goes 6 px → 0 px, both sharpening together (#033 Rack focus blurs one side)
- Timing: 0.5 s to 3.4 s (2.9 s), cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1))
- Focus markers: blue corner brackets on both the flower (half-width 46 px) and the person (half-width 30 px), opacity 0 → 1 as focus arrives
- Return: hold 3.4–4.2 s, then cross-fade back to the start over the last 0.5 s; top-right readout shows the aperture (f/1.8 → f/16)

Canvas: 539×208; cycle: 9.4s.

  // @element 14
    CELLS[13] = shot(camCell((k, w, h, p) => {
    world(k, w, h, cam({
      y: 1.1
    }), {
      person: {
        x: .9,
        z: 9
      },
      blurFg: 5 * (1 - p),
      blurBg: 6 * (1 - p),
      extra: [ [ -.75, 0, 2, (kk, s) => {
        kk.fillStyle = C.g3;
        kk.fillRect(-.025, 0, .05, .75);
        kk.fillStyle = C.blueM;
        for (let i = 0; i < 6; i++) {
          kk.beginPath();
          kk.ellipse(Math.cos(i) * .09, .8 + Math.sin(i) * .09, .08, .05, i, 0, 7);
          kk.fill();
        }
        kk.fillStyle = C.blue;
        kk.beginPath();
        kk.arc(0, .8, .05, 0, 7);
        kk.fill();
      }, true ] ],
      after: (kk, cc) => {
        kk.globalAlpha = p;
        kk.strokeStyle = C.blue;
        kk.lineWidth = 2;
        kk.beginPath();
        [ [ proj(cc, -.75, .8, 2), 46 ], [ proj(cc, .9, .9, 9), 30 ] ].forEach(([q, r]) => [ [ -1, -1 ], [ 1, -1 ], [ -1, 1 ], [ 1, 1 ] ].forEach(([sx, sy]) => {
          kk.moveTo(q.x + sx * r, q.y + sy * r - sy * 9);
          kk.lineTo(q.x + sx * r, q.y + sy * r);
          kk.lineTo(q.x + sx * r - sx * 9, q.y + sy * r);
        }));
        kk.stroke();
        kk.globalAlpha = 1;
      }
    });
  }, p => {
    const a = lerp(1.8, 16, p);
    return `f/${a < 10 ? a.toFixed(1) : Math.round(a)}`;
  }));
