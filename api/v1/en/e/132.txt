Motion Prompt #132 · Variable font animation
The same word goes smoothly from thin to very bold and back, with a slider below showing the weight.

- "MOTION" (112 px, system-ui, 2 px letter spacing). The weight goes back and forth twice per 4.7 s: v = 0.5 − 0.5·cos(2π × 2 × time ÷ 4.7), which eases at both ends.
- Weight = round(100 + 800v), from 100 to 900, set directly as the font weight.
- A slider below (x = 112→427, y = 180) labelled thin on the left and bold on the right. The knob (yellow, radius 14) follows v, with the current weight shown above it.

Canvas: 539×208; cycle: 4.7s.

  // @element 12
    CELLS[11] = (k, w, h, u) => {
    stage(k);
    const v = .5 - .5 * Math.cos(2 * Math.PI * 2 * u / CYC), wt = Math.round(100 + 800 * v);
    txt(k, MotionLocale.text("MOTION"), w / 2, 80, `${wt} 112px "Motion Sans"`, "#fff", "center", "middle", "2px");
    const x0 = 112, x1 = w - 112, y = 180, kx = x0 + (x1 - x0) * v;
    txt(k, MotionLocale.text("copy_010"), x0 - 34, y + 1, `300 30px ${FONT}`, C.dim, "center", "middle");
    txt(k, MotionLocale.text("copy_011"), x1 + 34, y + 1, `900 30px ${FONT}`, C.dim, "center", "middle");
    k.fillStyle = C.navy3;
    rr(k, x0, y - 5, x1 - x0, 10, 5);
    k.fill();
    k.fillStyle = C.blue;
    rr(k, x0, y - 5, Math.max(10, kx - x0), 10, 5);
    k.fill();
    k.fillStyle = C.yel;
    k.beginPath();
    k.arc(kx, y, 14, 0, 7);
    k.fill();
    txt(k, String(wt), kx, y - 30, `800 24px ${DISP}`, C.yel, "center", "middle");
  };
