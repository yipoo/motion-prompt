Motion Prompt #014 · Motion trail
A ball moving in a figure eight leaves a fading trail of copies behind it.

- A ball (coral, radius 25, white centre radius 11) traces a figure eight once per 4.7 s: x = 196·sin(a), y = 62·sin(2a), with a advancing at constant speed.
- 15 copies, each placed 0.105 rad (about 0.079 s) further back along the path.
- Copy radius goes 22→6 and opacity is 0.9 × (1 − i/15) + 0.05, so older copies are smaller and fainter.
- Copy colour runs coral → yellow → blue from newest to oldest.
- Draw the oldest copy first and the ball itself last.

Canvas: 539×208; cycle: 4.7s.

  // @element 14
    CELLS[13] = (k, w, h, u) => {
    stage(k);
    const X = w / 2, Y = h / 2 + 2, A = 196, B = 62, th = u / CYC * Math.PI * 2;
    const pt = a => [ X + A * Math.sin(a), Y + B * Math.sin(2 * a) ];
    const N = 15;
    for (let i = N; i >= 1; i--) {
      const [x, y] = pt(th - i * .105), f = i / N;
      k.globalAlpha = .9 * (1 - f) + .05;
      k.fillStyle = f < .5 ? mix(C.coral, C.yel, f * 2) : mix(C.yel, C.blue, (f - .5) * 2);
      k.beginPath();
      k.arc(x, y, lerp(22, 6, f), 0, 7);
      k.fill();
    }
    k.globalAlpha = 1;
    const [x, y] = pt(th);
    k.fillStyle = C.coral;
    k.beginPath();
    k.arc(x, y, 25, 0, 7);
    k.fill();
    k.fillStyle = "#fff";
    k.beginPath();
    k.arc(x, y, 11, 0, 7);
    k.fill();
  };
