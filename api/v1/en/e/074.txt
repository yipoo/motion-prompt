Motion Prompt #074 · Fade-in on scroll
As the page scrolls, the heading, the cards and the body text each rise into place and fade in when they enter the view.

- Scroll: 0→95 px at 0.35–1.0 s, 95→200 px at 1.5–2.1 s, 200→0 at 3.2–4.4 s (all cubic ease-in-out).
- Trigger line at 85% of the viewport height (143 px from the top). An element fires when its top edge passes above it (the Intersection Observer idea).
- After firing, over 0.7 s: opacity 0→1 and offset 28 px below → 0 (cubic ease-out).
- Three elements: the heading (172 px down the page), a row of three cards (206 px) and body text (334 px), all below the view at first. The cards in the row appear together.
- When an element leaves the bottom of the view on the way back up, it is reset out of sight and plays again next time.

Canvas: 539×208; cycle: 4.8s.

    frame(k);
    const SY = t => steps([ [ .35, 0 ], [ 1, 95 ], [ 1.5, 95 ], [ 2.1, 200 ], [ 3.2, 200 ], [ 4.4, 0 ] ], t), y = SY(u);
    const LINE = VH * .85, DUR = .7, RISE = 28;

      bars(k, 34, 68, 190, 3);

      const items = [ [ 172, () => txt(k, MotionLocale.text("copy_157"), VW / 2, 172 + 20, `800 18px ${FONT}`, C.ink, "center") ], [ 206, () => {
        for (let i = 0; i < 3; i++) {
          const x = 34 + i * 152;
          k.fillStyle = C.soft;
          rr(k, x, 206, 136, 106, 8);
          k.fill();
          pic(k, x + 8, 214, 120, 56, i, 5);
          bars(k, x + 10, 280, 112, 2, "#CBD2DE");
        }
      } ], [ 334, () => bars(k, 110, 334, 290, 3, C.faint, 7, 13) ] ];
      for (const [top, draw] of items) {
        const t0 = enteredAt(SY, top, LINE, u);
        if (t0 === null) continue;
        const q = eOut(P(u, t0, t0 + DUR));
        k.save();
        k.globalAlpha = q;
        k.translate(0, RISE * (1 - q));
        draw();
        k.restore();
      }
      k.restore();
      sbar(k, y / 200, .5);
    });
