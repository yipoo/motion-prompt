Motion Prompt #130 · Wave text
The letters of "WAVE TEXT" rise and fall one after another, like a wave.

- "WAVE TEXT" (70 px, bold, 4 px letter spacing). Three waves per 4.7 s (1.567 s per wave).
- Vertical offset of letter i = −28·sin(φ − 0.62i), with φ = 2π × 3 × time ÷ 4.7 (each letter lags the previous by 0.62 rad).
- Rising letters stretch vertically (1 + 0.06·s) and shift from white towards yellow (s is the sine value, clamped to 0–1 for the colour).
- A shadow ellipse under each letter shrinks as the letter rises.

Canvas: 539×208; cycle: 4.7s.

  // @element 10
    CELLS[9] = (k, w, h, u) => {
    stage(k);
    const f = `800 70px ${DISP}`, cs = chars(k, MotionLocale.text("WAVE TEXT"), f, 4), Y = h / 2 + 2, ph = 2 * Math.PI * 3 * u / CYC;
    cs.forEach((c, i) => {
      if (c.ch === " ") return;
      const s = Math.sin(ph - i * .62), y = -28 * s;
      k.fillStyle = "rgba(0,0,0,.3)";
      k.beginPath();
      k.ellipse(w / 2 + c.x, Y + 62, c.w * (.42 - .12 * s), 4, 0, 0, 7);
      k.fill();
      k.save();
      k.translate(w / 2 + c.x, Y + y);
      k.scale(1, 1 + .06 * s);
      txt(k, c.ch, 0, 0, f, mix("#FFFFFF", C.yel, clamp(s)), "center", "middle");
      k.restore();
    });
  };
