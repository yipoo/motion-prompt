Motion Prompt #257 · Tracking breathe
A centred word expands and contracts its letter spacing.

- 539×208 px Canvas 2D card; 4.8 s deterministic seamless loop. Unless stated otherwise q=(1−cos(2πt/4.8))/2.
- Use bold 38 px Motion Sans; measure each glyph before centring the whole word.
- Gap between glyphs is 4+18q px, changing smoothly between 4 and 22 px.

Canvas: 539×208; cycle: 4.8s.

Dependencies: api/v1/kit/vector.js + studio/locale.js + assets/fonts/NotoSansSC.woff2
Set document.documentElement.lang to en. Load Motion Sans before drawing.
Reference source: studio/packs/vector.js

  // @element 17
  CELLS[16]=wrap((k,p)=>{let s=lang('MOTION','动态设计'),gap=4+18*wave(p);k.font='700 38px "Motion Sans",sans-serif';let ws=Array.from(s).map(c=>k.measureText(c).width),total=ws.reduce((a,b)=>a+b,0)+gap*(s.length-1),x=(CW-total)/2;k.fillStyle=C.ink;k.textAlign='left';k.textBaseline='middle';Array.from(s).forEach((c,i)=>{k.fillText(c,x,104);x+=ws[i]+gap;});});
