Motion Prompt #161 · View transition (shared element)
Clicking a photo in the list grows that same photo into the image at the top of the detail page while the rest changes to the detail page; going back shrinks it into place.

- A 511 × 168 viewport with three photos in a list (143 × 80, radius 6). The middle photo is clicked at 0.75 s, and "← Back to list" (back to list) on the detail page at 3.05 s. One pass takes 4.7 s (twice per 9.4 s pack cycle).
- Forward: over 0.85–1.45 s (0.6 s, cubic ease-in-out) the clicked photo moves and resizes continuously from its list slot to the 479 × 94 image at the top of the detail page (radius 8). It stays one photo throughout.
- The other photos and the heading fade out over the first 62% of the move; the detail title, text and back button fade in over the last 40%. At 50% the URL changes from /works to /works/02.
- Back: over 3.15–3.75 s (0.6 s) the same move runs in reverse to the list slot.
- This is how the View Transitions API looks when the list photo and the detail photo share the same view-transition-name.

Canvas: 539×208; cycle: 9.4s.

      w: VW - 32,

    const cur = t => path([ [ 0, 420, 205 ], [ .5, 262, 88 ], [ .95, 262, 88 ], [ 1.6, 380, 150 ], [ 2.55, 380, 150 ], [ 2.9, 62, 30 ], [ 3.2, 62, 30 ], [ 3.9, 420, 205 ], [ 4.7, 420, 205 ] ], t);

        bars(k, G[i], GY + GH + 30, 90, 1, C.faint, 5);
      }
      k.restore();
      const x = lerp(G[1], T.x, e), y = lerp(GY, T.y, e), ww = lerp(GW, T.w, e), hh = lerp(GH, T.h, e);

      const da = clamp((e - .6) / .4);

        k.globalAlpha = da;
        k.fillStyle = "rgba(255,255,255,.92)";
        rr(k, 26, 19, 74, 22, 11);
        k.fill();
        txt(k, MotionLocale.text("copy_145"), 63, 30.5, `700 11px ${FONT}`, C.ink, "center", "middle");

        k.restore();
      }
