Motion Prompt #324 · Glass shine tracking
A broad radial sheen moves inside a clipped translucent panel. The canvas is a deterministic motion demonstration, not a connected control.

- Clip a 115px-radius gradient to a 220×102px panel with 22px corners; move the highlight on a 2400ms ellipse. In production use normalized pointer coordinates and a static sheen on touch devices.
- Reference canvas: 539×208 CSS pixels; preview cycle 4800ms. Scale uniformly for other sizes.
- Keep motion deterministic when scrubbing. Honor reduced motion with a stable keyframe, preserve readable labels, and do not depend on color alone.

Canvas: 539×208; cycle: 4.8s.
