Motion Prompt #266 · Coverflow
Seven covers travel around a depth-sorted carousel.

- Seven cards use phase q = a + i·2π/7, x = 190 sin(q) and depth z = 105 cos(q).
- Cards are drawn from far to near with perspective factor 360/(360+z); height is 91 times that factor.
- Card width is (35+34|sin(q)|) times the perspective factor; four accent colors repeat and all cards complete one orbit every 4.8 s.

Canvas: 539×208; cycle: 4.8s.

Dependencies: api/v1/kit/spatial.js + studio/locale.js + assets/fonts/NotoSansSC.woff2

Reference source: studio/packs/spatial.js

  // @element 02
  CELLS[1] = scene('COVERFLOW', '封面流', a => {
    const cards = []; for (let i=0;i<7;i++) { const q=a+i*TAU/7; cards.push({ x:Math.sin(q)*190,z:Math.cos(q)*105,q,i }); }
    cards.sort((a,b)=>b.z-a.z).forEach(c=>{ const p=project(c.x,7,c.z); const w=(35+34*Math.abs(Math.sin(c.q)))*p[2]; miniCard(p[0],p[1],w,91*p[2],[C.blue,C.mint,C.coral,C.gold][c.i%4],c.i+1); });
    line([[84,179],[455,179]],C.grid);
  });
