Implement "Typewriter", Motion Prompt #006.

What the sample shows: Text is typed into an input field one character at a time, then the send button lights up and is pressed.

Motion spec:
- One pass per 4.7 s. Nine characters appear in a white input field (471 × 92, radius 30), one every 0.24 s starting at 0.3 s (typing ends at 2.46 s).
- Each new character settles from scale 1.35 to 1: 1 + 0.35·e^(−16t).
- Cursor (coral, 5 × 44) sits after the last character: solid while typing, otherwise blinking with a 0.94 s period (on for 0.5 s).
- Send button (radius 30): grey, then a blue disc appears from 2.58 s with spring 1 − e^(−6.5t)·cos(15t).
- Press: the button shrinks by up to 20% at 2.96–3.21 s (half sine). At 3.13–3.41 s the text moves 70 px up while fading out.
- The cursor returns to the start once the text is half faded (about 3.27 s); at 3.51–3.81 s the blue fades.

When to use it: Use it to show someone typing: a prompt, a search query, a chat message.

Language: English, including text inside animated demos. Bundle assets/fonts/NotoSansSC.woff2 (Motion Sans) for Chinese and multilingual glyphs; do not depend on installed or remote fonts.
Canvas: 539 × 208 px; loop: 4.7 seconds. Preserve the reference shapes, timing and easing; adapt text, colours and assets only. Support responsive layouts and prefers-reduced-motion.
