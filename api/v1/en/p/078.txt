Implement "Scroll snap", Motion Prompt #078.

What the sample shows: After a small scroll, the page carries itself the rest of the way until the next section's top lines up with the top of the view.

Motion spec:
- Each section is as tall as the viewport (168 px). The first is pale blue, the second navy.
- One snap per 2.4 s. At 0.45–0.85 s the user scrolls only 34 px (cubic ease-out).
- At 0.9–1.5 s the page moves the remaining 134 px by itself and lines up the next section's top (cubic ease-out).
- The second 2.4 s does the same upward, back to the first section (the behaviour of scroll-snap-type: y mandatory).

When to use it: Use it for a page that should read one full screen at a time, like slides.

Language: English, including text inside animated demos. Bundle assets/fonts/NotoSansSC.woff2 (Motion Sans) for Chinese and multilingual glyphs; do not depend on installed or remote fonts.
Canvas: 539 × 208 px; loop: 4.8 seconds. Preserve the reference shapes, timing and easing; adapt text, colours and assets only. Support responsive layouts and prefers-reduced-motion.
