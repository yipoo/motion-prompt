Implement "Magnetic button", Motion Prompt #084.

What the sample shows: As the cursor comes near, the button is drawn toward it and follows; when the cursor leaves, the button wobbles back to its place.

Motion spec:
- A 168 × 52 button (orange, radius 26) in the centre. The pull range is a 110 px radius from the button's centre.
- Inside the range: target offset = (cursor − button centre) × 0.35; every frame (60 fps) the button covers 18% of the way to the target.
- On leaving the range it returns from its current offset to 0 over 1.1 s with elastic.out(1, 0.3): 2^(−10x)·sin((x − 0.075)·2π/0.3) + 1.
- The cursor enters from the left, circles the button and leaves to the right.

When to use it: Use it on the one button you most want clicked, such as sign-up or contact.

Language: English, including text inside animated demos. Bundle assets/fonts/NotoSansSC.woff2 (Motion Sans) for Chinese and multilingual glyphs; do not depend on installed or remote fonts.
Canvas: 539 × 208 px; loop: 4.8 seconds. Preserve the reference shapes, timing and easing; adapt text, colours and assets only. Support responsive layouts and prefers-reduced-motion.
