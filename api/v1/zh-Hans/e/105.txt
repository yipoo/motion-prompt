Motion Prompt #105 · 散景
光圈打开时，焦点上的人物保持清晰，背后建筑变柔，路灯和远处灯光扩散成大而浅的圆斑。

- 场景 2：街角；y 132–162 的道路后方有建筑、树木和路灯（x 114、292、494）；人物站在左前方，双脚位于 x 176、y 200，身高 124 px。背景转为较暗场景，天空 #E7E5E1。
- 背景模糊度（人物以外的全部内容）0→6 px。
- 灯光：三盏路灯尺寸系数 1.25，另有 12 个间隔 45 px 的光点，y 44–114、尺寸系数 0.6–1.2，随机种子固定；圆斑半径 = (2.4 + 15 × 效果强度) × 尺寸系数。
- 圆斑不透明度 100%→55%；路灯为琥珀色 #FFC75A，远处灯光为 #FFE3A3，带 1.2 px 琥珀色边缘。
- 人物保持清晰；右上角光圈 f/16→f/1.4，共 8 档。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

  // @element 09
    CELLS[8] = cell((k, u) => {
    const a = env(u), p = pal(BASE, DIM, a);
    const [B, kb] = layer("bokeh");
    stageStreet(kb, p, {
      person: false
    });
    const [Bb, kbb] = layer("bokeh-b");
    kbb.filter = `blur(${(6 * a).toFixed(2)}px)`;
    kbb.drawImage(B, 0, 0);
    kbb.filter = "none";
    k.drawImage(B, 0, 0);
    k.drawImage(Bb, 0, 0);
    const pts = once("bokeh-pts", () => {
      const o = LAMPS.map(x => [ x + 9, ROAD - 53, 1.25, 0 ]), r = rng(9);
      for (let i = 0; i < 12; i++) o.push([ 22 + i * 45 + r() * 20, 44 + r() * 70, .6 + r() * .6, 1 ]);
      return o;
    });
    k.save();
    for (const [x, y, s, w] of pts) {
      const r = (2.4 + 15 * a) * s;
      k.globalAlpha = lerp(1, .55, a);
      k.fillStyle = w ? BASE.glow : BASE.lit;
      k.beginPath();
      k.arc(x, y, r, 0, TAU);
      k.fill();
      k.globalAlpha = .7 * a;
      k.strokeStyle = BASE.lit;
      k.lineWidth = 1.2;
      k.stroke();
    }
    k.restore();
    figure(pen(k), FIG[0], FIG[1], FIG[2], p.person);
    const stops = [ "f/16", "f/11", "f/8", "f/5.6", "f/4", "f/2.8", "f/2", "f/1.4" ];
    hud(k, stops[Math.round(a * 7)]);
  });
