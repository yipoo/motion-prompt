Motion Prompt #267 · 实体立方体
彩色立方体持续旋转，保持实体纵深。

- 立方体边长 106，八个顶点绕 Y 轴旋转 a，再绕 X 轴固定倾斜 0.35 rad。
- 六个四边形面按平均纵深排序后绘制；透视焦距为 360 px。
- 每个面使用独立强调色和深色边线；y = 186 处有半径 77 × 6 px 的静态地面椭圆。

Canvas: 539×208; cycle: 4.8s.

Dependencies: api/v1/kit/spatial.js + studio/locale.js + assets/fonts/NotoSansSC.woff2
Set document.documentElement.lang to zh-CN. Load Motion Sans before drawing.
Reference source: studio/packs/spatial.js

  // @element 03
  CELLS[2] = scene('SOLID CUBE', '实体立方体', a => {
    const vs=[[-53,-53,-53],[53,-53,-53],[53,53,-53],[-53,53,-53],[-53,-53,53],[53,-53,53],[53,53,53],[-53,53,53]].map(p=>rotate(p,a,.35));
    const faces=[[0,1,2,3],[4,7,6,5],[0,4,5,1],[3,2,6,7],[1,5,6,2],[0,3,7,4]];
    faces.map((f,i)=>({f,i,z:f.reduce((s,j)=>s+vs[j][2],0)/4})).sort((a,b)=>b.z-a.z).forEach(({f,i})=>poly(f.map(j=>project(...vs[j])),[C.blue,C.mint,C.coral,C.gold,'#5268b0','#529f9c'][i],C.bg));
    ellipse(269.5,186,77,6,'#080e1c',true);
  });
