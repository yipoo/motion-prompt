Motion Prompt #116 · 双色调
同一风景的色彩替换为仅由两种颜色构成的色阶：暗部为靛蓝色，亮部为粉色。

- 场景 3：左侧为半身像（头部中心 x 140、y 82，半径 28 px），右侧有山丘、房屋、树木和太阳（x 432、y 54，半径 15 px）。
- 双色：暗端为 #1F2A5C，亮端为 #FF9FB2。
- 转换：根据每种颜色的亮度 L，计算 t = ((L − 70) / 180)^2.4，再按 t 混合两种颜色，从而拉开亮调层次。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

Canvas: 539×208; cycle: 5s.

  // @element 20
    CELLS[19] = cell((k, u) => {
    const a = env(u);
    const DUO = mapPal(BASE, c => mixc("#1F2A5C", "#FF9FB2", Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
    stageLand(k, pal(BASE, DUO, a));
  });
