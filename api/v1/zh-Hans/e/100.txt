Motion Prompt #100 · 分割光
灯光从近正面 20° 转向正侧面 90°；头部阴影从月牙形扩大到恰好一半，将面部沿中央分开。

- 场景 1：地平线位于 y 150，前方为肩部以上的人物（头部中心 x 270、y 78，半径 29 px，无面部或头发）。背景转为较暗场景，天空 #E7E5E1。
- 光源从画面左侧照来，角度 20°→90°；右下角显示平面图，右上角读数“90° · ↑0°”。
- 头部：x = 270 + cos(angle)·√(29² − dy²) 右侧为阴影 #33405A，左侧为亮部 #FFC75A；90° 时边界为笔直的中线。
- 身体半宽 56 px：x = 270 + cos(angle)·56 右侧为阴影，左侧边缘的一条窄带受光。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

  // @element 04
    CELLS[3] = cell((k, u) => {
    const a = env(u), az = lerp(.35, Math.PI / 2, a);
    stagePortrait(k, pal(BASE, DIM, a));
    const lit = mixc(BASE.person, BASE.lit, a), sh = mixc(BASE.person, BASE.shade, a), W = torsoW(PR);
    bust(k, PX, PY, PR, BASE.person, kk => {
      kk.fillStyle = lit;
      kk.beginPath();
      kk.arc(PX, PY, PR, 0, TAU);
      kk.fill();
      headShade(kk, PX, PY, PR, az, 1, sh);
      torso(kk, PX, PY, PR, PX - W, PX - Math.cos(az) * .4 * W - .4 * W, lit);
      torso(kk, PX, PY, PR, PX + Math.cos(az) * W, PX + W, sh);
    });
    plan(k, [ [ az, a ] ]);
    hud(k, `${Math.round(az * 180 / Math.PI)}° · ↑0°`);
  });
