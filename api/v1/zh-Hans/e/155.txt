Motion Prompt #155 · 悬停切换图片
光标悬停产品卡片时，T 恤正面照片交叉淡化为背面；离开后恢复正面。

- 视口 511 × 168，有两张产品卡片（照片框 196 × 112，圆角半径 8，下方为名称和价格）。光标先后在左、右卡片各停留约 1.3 s。一轮 4.7 s（每个 9.4 s 的效果包周期两轮）。
- 悬停时，在 0.3 s 内（二次缓入缓出）由正面照片（胸口小圆点）交叉淡化为背面照片（背部大星星）；离开时用相同的 0.3 s 淡回。
- 照片下方两个半径 3 的圆点表示当前照片，深色点为当前项。
- 整个卡片均为悬停区域，包含名称。照片框、名称和价格均不移动。

Canvas: 539×208; cycle: 9.4s.

    function tee(k, x, y, s, col, back) {
    k.save();
    k.translate(x, y);
    k.scale(s, s);
    k.fillStyle = col;
    k.beginPath();
    k.moveTo(-.36, -.5);
    k.quadraticCurveTo(0, back ? -.44 : -.3, .36, -.5);
    [ [ .66, -.3 ], [ .52, -.08 ], [ .38, -.18 ], [ .38, .56 ], [ -.38, .56 ], [ -.38, -.18 ], [ -.52, -.08 ], [ -.66, -.3 ] ].forEach(([a, b]) => k.lineTo(a, b));
    k.closePath();
    k.fill();
    k.strokeStyle = "rgba(28,35,51,.18)";
    k.lineWidth = .025;
    k.beginPath();
    k.moveTo(-.36, -.5);
    k.quadraticCurveTo(0, back ? -.44 : -.3, .36, -.5);
    k.stroke();
    k.restore();
  }
