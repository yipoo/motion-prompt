Motion Prompt #136 · 线条抖动
手绘线稿每隔几帧轻微抖动，画面内容本身保持不动。

- 静态线稿包含黄色星星、白色云朵、薄荷色闪光线及淡淡的地面线。线宽 6–8，圆形端点。
- 图画本身不移动。每 4.7 s 重绘 47 次（约每 0.1 s 一次），每个点在 x、y 方向各加入最大 ±3.5 px 的固定随机偏移。
- 先把每条线转换为点列（间距 6–13 px；云朵轮廓 96 个点），再通过相邻点的中点绘制二次曲线，使其像手绘帧一样抖动。
- 偏移由帧编号和点编号的哈希计算，因此同一帧的外观始终相同。

    function densify(pts, closed, step) {
    const out = [], n = pts.length, m = closed ? n : n - 1;
    for (let i = 0; i < m; i++) {
      const a = pts[i], b = pts[(i + 1) % n], d = Math.hypot(b[0] - a[0], b[1] - a[1]), c = Math.max(1, Math.round(d / step));
      for (let j = 0; j < c; j++) out.push([ lerp(a[0], b[0], j / c), lerp(a[1], b[1], j / c) ]);
    }
    if (!closed) out.push(pts[n - 1]);
    return out;
  }
