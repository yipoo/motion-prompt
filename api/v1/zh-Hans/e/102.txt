Motion Prompt #102 · 蝴蝶光
位于面部正前方高处的光源亮起；脸部两侧均匀受光，只有下巴下方出现一个小而对称的阴影。

- 场景 1：地平线位于 y 150，前方为肩部以上的人物（头部中心 x 270、y 78，半径 29 px，无面部或头发）。背景转为较暗场景，天空 #E7E5E1。
- 头部全部受光，颜色 #FFC75A，没有阴影侧。
- 下巴阴影：椭圆中心 y 78+1.06R，宽 0.72R、高 0.38R，R = 29，即约 21×11 px，颜色 #33405A。
- 身体：中心两侧 ±0.8×56 px 内受光，外缘窄条保留底色；平面图显示光源位于镜头侧 0°，右上角读数“0° · ↑45°”。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

Canvas: 539×208; cycle: 5s.

  // @element 06
    CELLS[5] = cell((k, u) => {
    const a = env(u), R = PR, W = torsoW(R);
    stagePortrait(k, pal(BASE, DIM, a));
    const lit = mixc(BASE.person, BASE.lit, a), sh = mixc(BASE.person, BASE.shade, a);
    bust(k, PX, PY, R, BASE.person, kk => {
      torso(kk, PX, PY, R, PX - .8 * W, PX + .8 * W, lit);
      kk.fillStyle = sh;
      kk.beginPath();
      kk.ellipse(PX, PY + R * 1.06, R * .72, R * .38, 0, 0, TAU);
      kk.fill();
      kk.fillStyle = lit;
      kk.beginPath();
      kk.arc(PX, PY, R, 0, TAU);
      kk.fill();
    });
    plan(k, [ [ 0, a ] ]);
    hud(k, "0° · ↑45°");
  });
