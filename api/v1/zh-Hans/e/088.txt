Motion Prompt #088 · 离站挽留弹窗
光标从页面顶部向标签页或关闭按钮移出时，页面变暗并打开“等等！”弹窗。点击 × 可关闭。

- 光标在 0.7–1.25 s 从页面向浏览器地址栏上移（cubic ease-in-out）。
- 光标越过视口顶边时触发（y = 0，约 1.07 s），与 document 的 mouseleave 事件中检查 clientY ≤ 0 相同。
- 触发后 0.05–0.45 s 打开（cubic ease-out）：藏青色背景遮罩不透明度 0→0.5；弹窗（260×132、圆角 12）不透明度 0→1、缩放 0.9→1。
- 内部有标题、一行橙色折扣文字、优惠券按钮，以及右上角的 ×。
- 2.9 s 点击 ×；在此后 0.03–0.25 s 线性消失。

Canvas: 539×208; cycle: 4.8s.

    while (TRIG < 1.3 && path([ [ .7, 300, 120 ], [ 1.25, 360, -18 ] ], TRIG)[1] >= 0) TRIG += 1 / 240;
    const m = eOut(P(u, TRIG + .05, TRIG + .45)) * (1 - P(u, CLOSE + .03, CLOSE + .25));

        k.fillRect(0, 0, VW, VH);

        k.translate(-D.w / 2, -D.h / 2);

        k.beginPath();

        k.lineTo(D.w - 14, 26);
        k.moveTo(D.w - 14, 14);
        k.lineTo(D.w - 26, 26);
