Motion Prompt #138 · 百叶窗转场
一排细条中的开口逐渐扩大，直至完全显露下一场景。

- 白天场景→夜晚场景→白天，每段 2.35 s。七条水平条带，每条高 208 ÷ 7 ≈ 29.7 px。
- 0.4–1.65 s（持续 1.25 s），二次缓入缓出：所有条带同时从顶边向下显露下一场景，开口高度从 0 增至整条高度。
- 前一场景保留在下层，两幅画面均不移动。

Canvas: 539×208; cycle: 4.7s.

  // @element 18
    CELLS[17] = abCell((k, w, h, u, a, b) => {
    const p = eIOs(P(u, TA - .1, TB + .15)), N = 7, sh = h / N, S = [ scrA, scrB ];
    S[a](k, w, h);
    if (p <= 0) return;
    k.save();
    k.beginPath();
    for (let i = 0; i < N; i++) k.rect(0, i * sh, w, sh * p + (p > .999 ? 1 : 0));
    k.clip();
    S[b](k, w, h);
    k.restore();
  });
