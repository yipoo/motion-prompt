Motion Prompt #080 · 荧光笔标记动画
文案滚入视口时，关键词下半部出现一道从左向右绘制的黄色荧光笔划。

- 滚动量：0.35–1.0 s 为 0→90 px，1.6–2.2 s 为 90→180 px，3.3–4.4 s 为 180→0（cubic ease-in-out）。
- 两行文案（20 px，粗体）位于页面向下 190 px 和 290 px 处，初始隐藏在视口下方。
- 某行顶部越过触发线（视口高度的 80%，即 134 px）后，其关键词下方开始绘制笔划。
- 笔划为黄色 #FFE36B，高 11，位于文字下部（基线上方 8 px 到下方 3 px）。宽度在 0.8 s 内从左侧由 0 增至关键词宽度（cubic ease-out），绘制于文字背后。
- 离开视口底部的文字行在视野外重置。

Canvas: 539×208; cycle: 4.8s.

  // @element 08
    CELLS[7] = (k, w, h, u) => {
    frame(k);
    const SY = t => steps([ [ .35, 0 ], [ 1, 90 ], [ 1.6, 90 ], [ 2.2, 180 ], [ 3.3, 180 ], [ 4.4, 0 ] ], t), y = SY(u);
    const LINE = VH * .8, DUR = .8, MARK = "#FFE36B", F = `800 20px ${FONT}`;
    const rows = [ [ 190, [ MotionLocale.text("copy_090"), MotionLocale.text("copy_156"), MotionLocale.text("copy_095") ] ], [ 290, [ MotionLocale.text("copy_094"), MotionLocale.text("copy_147"), MotionLocale.text("copy_093") ] ] ];
    view(k, () => {
      k.save();
      k.translate(0, -y);
      txt(k, MotionLocale.text("copy_089"), 70, 50, `700 14px ${FONT}`, C.sub);
      txt(k, MotionLocale.text("copy_148"), 70, 80, `800 24px ${FONT}`, C.ink);
      bars(k, 70, 96, 330, 4, C.faint, 6, 12, .8);
      for (const [base, parts] of rows) {
        k.font = F;
        const ws = parts.map(s => k.measureText(MotionLocale.text(s)).width);
        let x = (VW - ws.reduce((a, b) => a + b, 0)) / 2;
        const t0 = enteredAt(SY, base - 20, LINE, u), q = t0 === null ? 0 : eOut(P(u, t0, t0 + DUR));
        if (q > 0) {
          k.fillStyle = MARK;
          k.fillRect(x + ws[0], base - 8, ws[1] * q, 11);
        }
        parts.forEach((s, i) => {
          txt(k, s, x, base, F, i === 1 ? C.ink : "#4A5368");
          x += ws[i];
        });
        bars(k, 110, base + 22, 291, 2, C.faint, 6, 12, .7);
      }
      k.restore();
      sbar(k, y / 180, .5);
    });
  };
