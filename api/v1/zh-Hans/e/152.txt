Motion Prompt #152 · 滚动放大
页面滚动时，中间的小照片放大至铺满窗口，周围文字淡出，照片上浮现标题。

- 视口 511 × 168。滚动进度 p：0.3–2.3 s 从 0→1，3.0–4.4 s 从 1→0（三次缓入缓出）。一轮 4.7 s（每个 9.4 s 的效果包周期两轮）。
- 照片框从中央的 155 × 90（x = 178、y = 58，圆角半径 8）扩展至整个 511 × 168 窗口（圆角半径 0）；位置、宽、高及圆角半径随 p 成比例变化。
- 周围标题和正文在 p 从 0→0.45 时淡出（不透明度 1 − 2.2p）。
- p 从 0.7→1 时，照片中央淡入白色标题（字号 26 px，字距 2 px）。滚动条滑块随滚动移动。

Canvas: 539×208; cycle: 9.4s.

  // @element 08
    CELLS[7] = (k, w, h, u) => {
    u = snapU(u);
    frame(k);
    const p = steps([ [ .3, 0 ], [ 2.3, 1 ], [ 3, 1 ], [ 4.4, 0 ] ], u);
    const x = lerp(178, 0, p), y = lerp(58, 0, p), ww = lerp(155, VW, p), hh = lerp(90, VH, p);
    view(k, () => {
      const a = 1 - clamp(p * 2.2);
      k.save();
      k.globalAlpha = a;
      txt(k, MotionLocale.text("copy_109"), VW / 2, 38, `800 19px ${FONT}`, C.ink, "center");
      bars(k, 34, 66, 120, 4, C.faint, 6, 14);
      bars(k, 357, 66, 120, 4, C.faint, 6, 14);
      k.restore();
      pic(k, x, y, ww, hh, 0, lerp(8, 0, p));
      const b = clamp((p - .7) / .3);
      if (b > 0) {
        k.save();
        k.globalAlpha = b;
        txt(k, MotionLocale.text("copy_108"), VW / 2, VH / 2 + 2, `800 26px ${FONT}`, "#fff", "center", "middle", "2px");
        k.restore();
      }
      sbar(k, p * .6, .4);
    });
  };
