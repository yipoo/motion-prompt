Motion Prompt #050 · 抽屉面板
点击“菜单”后，高面板从左侧滑入；点击外侧则滑回。

- 542×191 卡片上的 4.5 秒周期。光标在 1.0 秒点击“菜单”按钮（110×34，左上角）。
- 展开程度 a：1.0–1.38 秒以 easeOutCubic 从 0 变为 1。整卡遮罩为 rgba(18,20,28)，不透明度 0.36·a。
- 面板：白色，宽 210，高度铺满卡片，x = −210 + 210·a，从左边缘滑入。阴影模糊 22，alpha 0.25。
- 内部：顶部有头像（半径 14）和姓名，下面四行菜单间隔 32 px；第一行以浅蓝色带标记为选中。
- 关闭：3.3 秒时光标点击外侧 (420, 120)；a 乘以 (1 − 3.3–3.65 秒区间内的 easeInOutCubic)，面板滑回。

    CELLS[1] = ui((w, h, t) => {
