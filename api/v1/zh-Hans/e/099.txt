Motion Prompt #099 · 剪影
按明亮晚霞设定曝光后，人物、建筑、路灯和树木都变成没有细节的纯黑形状，只有天空仍然明亮。

- 场景 1：地平线位于 y 150，前方为肩部以上的人物（头部中心 x 270、y 78，半径 29 px，无面部或头发）。
- 天空：顶部 #FAF9F7→#FFEDC4，地平线附近 y 92–150 为 #FFCF73 色带。
- 除天空外的物体变为 #2A2D36，远山为 #4A4546，人物为 #22252D。
- 太阳半径 20 px，位于 x 404，从 y 60 降至 y 128，被山丘遮住一半。
- 右上角读数：±0.0 EV→−2.0 EV。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

Canvas: 539×208; cycle: 5s.

  // @element 03
    CELLS[2] = cell((k, u) => {
    const a = env(u), INK = "#2A2D36";
    const SILH = mapPal(BASE, () => INK);
    Object.assign(SILH, {
      sky: "#FFEDC4",
      sky2: "#FFCF73",
      far: "#4A4546",
      sun: BASE.sun,
      glow: BASE.glow
    });
    stagePortrait(k, pal(BASE, SILH, a), {
      sun: [ 404, lerp(60, 128, a), 20, a ]
    });
    bust(k, PX, PY, PR, mixc(BASE.person, "#22252D", a));
    hud(k, `${(-2 * a).toFixed(1).replace("-0.0", "±0.0")} EV`);
  });
