Motion Prompt #248 · 呼吸螺旋
橙色三圈螺旋扩张、收缩并旋转。

- 539×208 px Canvas 2D 卡片，4.8 s 确定性无缝循环。除特别说明外 q=(1−cos(2πt/4.8))/2。
- 以 260 个点绘制以 (269,104) 为中心的三圈螺旋。
- 半径从 8 增至 43+43q px；每 4.8 s 旋转一圈，线宽 4 px。

Canvas: 539×208; cycle: 4.8s.

  // @element 08
  CELLS[7]=wrap((k,p)=>{let q=wave(p);line(k,Array.from({length:260},(_,i)=>{let a=i/259*TAU*3+TAU*p,r=8+i/259*(35+43*q);return[269+r*Math.cos(a),104+r*Math.sin(a)];}),C.orange,4);});
