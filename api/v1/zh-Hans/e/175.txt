Motion Prompt #175 · 固定镜头
人物从三脚架固定的相机前走过，汽车从后方驶过；相机连一个像素都不移动。

- 相机：完全固定，高度 1.4 m，朝向正前方，焦距 330 px；只有主体移动。
- 主体：人物在前方 6.5 m 处以恒速从左向右穿过，4.7 s 内 x 从 −6.2→+6.2 m；四肢按 sin(u×7)×0.42 rad 摆动。
- 灰色汽车在 15 m 远处从右向左驶过，4.7 s 内 x 从 +16→−16 m。
- 人物和汽车的起点、终点均在画面外，因此每 4.7 s 无缝循环。
- 左下角有灰色三脚架标记，右上角显示 LOCKED（#040 Freeze frame 会停止视频时间，此处时间继续，只有相机静止）。

Canvas: 539×208; cycle: 9.4s.

  // @element 07
    CELLS[6] = shot((k, w, h, u) => {
    const q = u / CYC;
    world(k, w, h, cam({
      y: 1.4
    }), {
      person: {
        x: lerp(-6.2, 6.2, q),
        z: 6.5,
        walk: u * 7
      },
      extra: [ [ lerp(16, -16, q), 0, 15, kk => {
        kk.fillStyle = C.g4;
        rr(kk, -1.9, .35, 3.8, .75, .25);
        kk.fill();
        rr(kk, -1.1, .95, 2.1, .62, .28);
        kk.fill();
        kk.fillStyle = C.ink;
        [ -1.15, 1.15 ].forEach(x => {
          kk.beginPath();
          kk.arc(x, .34, .34, 0, 7);
          kk.fill();
        });
      } ] ],
      after: kk => {
        kk.strokeStyle = C.g4;
        kk.lineWidth = 2.2;
        kk.lineCap = "round";
        const x = -w / 2 + 38, y = h / 2 - 20;
        kk.beginPath();
        kk.moveTo(x, y - 30);
        kk.lineTo(x - 12, y);
        kk.moveTo(x, y - 30);
        kk.lineTo(x + 12, y);
        kk.moveTo(x, y - 30);
        kk.lineTo(x, y - 2);
        kk.stroke();
        kk.fillStyle = C.g4;
        rr(kk, x - 9, y - 42, 18, 12, 3);
        kk.fill();
      }
    });
    return MotionLocale.text("LOCKED");
  });
