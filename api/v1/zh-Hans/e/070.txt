Motion Prompt #070 · 加载转圈
点击“发送”后，卡片上覆盖一层白色，中央的蓝色圆弧开始旋转；完成后变成勾号并淡出。

- 542×191 卡片，循环 4.5 s。光标在 1.0 s 点击底部中央的“发送”（120×40）。
- 1.05–1.2 s 期间以线性变化，在整张卡片上淡入白色遮罩（不透明度 0.78）和加载圆环。
- 加载圆环位于 (271, 92)：浅色底环半径 26、粗 6，上方为 243°（1.35π）的蓝色圆弧，端点为圆头，每秒旋转 1.3 圈（468°/s）。
- 加载圆环在 2.95–3.05 s 淡出；带白色勾号的蓝圆（半径 28）在 2.95–3.2 s 从 0.7→1 缩放（easeOutCubic）。
- 全部内容在 3.75–4.0 s 线性淡出。

  // @element 22
    CELLS[21] = ui((w, h, t) => {
    const load = seg(t, 1.05, 1.2) * (1 - seg(t, 2.95, 3.05));
    const done = seg(t, 2.95, 3.15) * (1 - seg(t, 3.75, 4));
    pageLines(24, 18, 494);
    strokeRR(24, 90, 494, 34, 7, C.line2, 1.5);
    fillRR(w / 2 - 60, 140, 120, 40, 8, C.blue);
    text(MotionLocale.text("copy_044"), w / 2, 160, 16, "#fff", 600, "center");
    const ov = Math.max(load, done);
    if (ov > 0) {
      X.fillStyle = `rgba(255,255,255,${.78 * ov})`;
      X.fillRect(0, 0, w, h);
      if (load > 0) {
        X.save();
        X.globalAlpha = load;
        ring(w / 2, 92, 26, "#e3e8f5", 6);
        X.beginPath();
        const a0 = t * Math.PI * 2 * 1.3;
        X.arc(w / 2, 92, 26, a0, a0 + Math.PI * 1.35);
        X.strokeStyle = C.blue;
        X.lineWidth = 6;
        X.lineCap = "round";
        X.stroke();
        X.restore();
      }
      if (done > 0) {
        X.save();
        X.globalAlpha = done;
        const s = .7 + .3 * eo(seg(t, 2.95, 3.2));
        X.translate(w / 2, 92);
        X.scale(s, s);
        circle(0, 0, 28, C.blue);
        check(0, 0, 11, "#fff", 4);
        X.restore();
      }
    }
    pointer([ [ .3, w + 30, h + 30 ], [ .95, w / 2 + 6, 166 ], [ 1.5, w / 2 + 6, 166 ], [ 2.2, w + 30, h + 30 ] ], [ 1 ], t);
  });
