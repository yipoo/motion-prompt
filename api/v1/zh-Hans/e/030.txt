Motion Prompt #030 · 环绕镜头
相机绕主体做圆周运动；人物保持居中，身后的树木和建筑横向掠过。

- 相机：以人物（位于前方 9 m 处）为圆心，沿半径 6 m 的圆周运动，从 −0.95 rad 到 +0.95 rad（−54° → +54°，总计约 109°）。
- 朝向：始终面对圆心（偏航角 = −angle）；高度 1.7 m，俯仰角固定为 −0.07 rad（约向下 4°）。
- 时序：0.5–3.6 秒（3.1 秒），三次方缓入缓出（约 cubic-bezier(0.65,0,0.35,1)）。
- 主体：人物不动；脸上的白点随角度横向移动；地面用半径 1.3 m 的虚线圆标示。
- 背景：12 棵树均匀分布在半径 10 m 的圆周上，随着镜头环绕从人物身后经过。
- 返回：3.6–4.2 秒保持，最后 0.5 秒交叉淡化返回；右上角显示角度（−54° → +54°）。

      z: P0[2] - Math.cos(a) * R,
      yaw: -a,
      y: 1.7,

      person: {
        z: 9,

      },

        kk.strokeStyle = C.blueM;
        kk.lineWidth = 2;
        kk.setLineDash([ 5, 5 ]);
        kk.beginPath();
        for (let i = 0; i <= 48; i++) {
          const b = i / 48 * Math.PI * 2;
          const q = proj(cc, Math.sin(b) * 1.3, 0, 9 + Math.cos(b) * 1.3);
          i ? kk.lineTo(q.x, q.y) : kk.moveTo(q.x, q.y);
        }
        kk.stroke();
        kk.setLineDash([]);
      }
    });
