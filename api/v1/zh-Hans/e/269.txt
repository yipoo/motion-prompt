Motion Prompt #269 · 纵深隧道
嵌套矩形框从明亮的消失点向外扩展。

- 十四个框架采用 q = (i/14+t/4.8) mod 1，围绕 (269,109) 的缩放为 s = 0.08+2.5q²。
- 每框半宽 110s、半高 54s，描边宽 1.5 px，蓝色与薄荷色交替。
- 不透明度 sin(πq) 隐藏两端重置；两条对角引导线和半径 3 px 的发光中心保持固定。

Canvas: 539×208; cycle: 4.8s.

Dependencies: api/v1/kit/spatial.js + studio/locale.js + assets/fonts/NotoSansSC.woff2
Set document.documentElement.lang to zh-CN. Load Motion Sans before drawing.
Reference source: studio/packs/spatial.js

  // @element 05
  CELLS[4] = scene('DEPTH TUNNEL', '纵深隧道', a => {
    for(let i=0;i<14;i++){const q=((i/14+a/TAU)%1), s=.08+q*q*2.5, alpha=Math.sin(Math.PI*q);X.save();X.globalAlpha=alpha;line([[269-110*s,109-54*s],[269+110*s,109-54*s],[269+110*s,109+54*s],[269-110*s,109+54*s]],i%2?C.blue:C.mint,1.5,true);X.restore();}
    line([[0,0],[269,109],[539,208]],C.grid);line([[539,0],[269,109],[0,208]],C.grid);glow(269,109,3,C.ink);
  });
