Motion Prompt #255 · 像素拼块
彩色像素拼块按固定散点顺序出现，再消散。

- 539×208 px Canvas 2D 卡片，4.8 s 确定性无缝循环。除特别说明外 q=(1−cos(2πt/4.8))/2。
- 使用 20×8 个 17 px 方块，网格间距 19 px。
- 延迟 = ((7x+11y) mod 23)/23；不透明度 = clamp(5(q−延迟))；蓝、薄荷绿、橙色交错。

Canvas: 539×208; cycle: 4.8s.

Dependencies: api/v1/kit/vector.js + studio/locale.js + assets/fonts/NotoSansSC.woff2

Reference source: studio/packs/vector.js

  // @element 15
  CELLS[14]=wrap((k,p)=>{let q=wave(p);for(let y=0;y<8;y++)for(let x=0;x<20;x++){let delay=((x*7+y*11)%23)/23, a=Math.max(0,Math.min(1,(q-delay)*5));k.globalAlpha=a;k.fillStyle=(x+y)%3===0?C.orange:(x+y)%3===1?C.blue:C.mint;k.fillRect(80+x*19,28+y*19,17,17);}k.globalAlpha=1;});
