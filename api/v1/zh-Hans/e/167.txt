Motion Prompt #167 · 向下滚动提示
首屏下方的 SCROLL、鼠标轮廓内的小点，以及两侧箭头，持续重复向下运动。

- 视口 511 × 168。首屏下方居中放置 SCROLL（字号 11 px，字距 3 px）及鼠标轮廓（24 × 38，圆角半径 12，线宽 2.2）。每拍 1.57 s（每 4.7 s 三拍，每 9.4 s 效果包周期六拍）。
- 内部橙色点尺寸 5 × 9，在每拍前 70% 时间内下移 14 px（二次缓入缓出），在 45%–75% 之间淡出，并于下一拍在顶部重新出现。
- 左右各 40 px 处，每侧两个向下折线箭头（线宽 2.5），相隔半拍，向下漂移 24 px；不透明度按正弦变化，0→0.8→0。

Canvas: 539×208; cycle: 9.4s.

      k.lineWidth = 2.2;
      rr(k, mx - 12, 126, 24, 38, 12);
      k.stroke();

      k.fillStyle = `rgba(255,90,44,${da})`;

      k.fill();
      [ mx - 40, mx + 40 ].forEach(x => {
        for (let j = 0; j < 2; j++) {
          const ff = mod(f + j * .5, 1), yy = 128 + ff * 24, al = Math.sin(Math.PI * ff);
          k.strokeStyle = `rgba(28,35,51,${.8 * al})`;
          k.lineWidth = 2.5;
          k.lineCap = "round";
          k.lineJoin = "round";
          k.beginPath();
          k.moveTo(x - 8, yy);
          k.lineTo(x, yy + 8);
          k.lineTo(x + 8, yy);
          k.stroke();
