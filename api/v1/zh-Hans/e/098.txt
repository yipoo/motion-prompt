Motion Prompt #098 · 轮廓光
周围环境变暗，人物后方左右两盏灯仅在头部和肩部两侧勾勒细亮边；右下方平面图显示两盏灯的位置。

- 场景 1：地平线位于 y 150，前方为肩部以上的人物（头部中心 x 270、y 78，半径 29 px，无面部或头发）。
- 背景由明亮场景变为暗场景，天空 #2B2D33、地面 #24252A；人物 #4D5A75→#1F2128。
- 亮边：在深色人物后放置两个琥珀色 #FFC75A 的人物副本，分别左右偏移 3.5 px，同时上移 2.5 px，形成宽 3.5 px 的边缘。
- 右下角平面图 66×66 px：俯视下灯光位于 ±135°，即后方左右两侧；右上角读数为“±135°”。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

  // @element 02
    CELLS[1] = cell((k, u) => {
    const a = env(u);
    stagePortrait(k, pal(BASE, DARK, a));
    k.save();
    k.globalAlpha = a;
    k.fillStyle = BASE.lit;
    for (const dx of [ -3.5, 3.5 ]) {
      k.save();
      k.translate(dx, -2.5);
      bustPath(k, PX, PY, PR);
      k.fill();
      k.restore();
    }
    k.restore();
    bust(k, PX, PY, PR, mixc(BASE.person, DARK.person, a));
    plan(k, [ [ Math.PI * .75, a ], [ -Math.PI * .75, a ] ]);
    hud(k, "±135°");
  });
