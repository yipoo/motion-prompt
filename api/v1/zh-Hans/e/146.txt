Motion Prompt #146 · 滚动文字显现
随着页面滚动，浅灰色标题从左上角开始逐字变深；向上滚动时则从末尾逐字变淡。

- 视口 511 × 168。滚动进度 p：0.3–2.6 s 从 0→1，3.2–4.4 s 从 1→0（三次缓入缓出）。页面上移 p × 40 px。一轮 4.7 s（每个 9.4 s 的效果包周期两轮）。
- 标题分三行，共 24 个字符，字号 27 px，字重 800，行高 38 px，初始均为浅灰色 #D6DBE4。
- 字符 n（从 0 开始）的变深程度为 clamp(p × 26 − n)：每个字符用 1/26 的进度达到正文色 #1C2333，与滚动同步。
- 向上滚动时按同一公式从最后一个字符开始淡化。正文示意条和滚动条滑块随页面移动。

Canvas: 539×208; cycle: 9.4s.

  // @element 02
    CELLS[1] = (k, w, h, u) => {
    u = snapU(u);
    frame(k);
    const p = steps([ [ .3, 0 ], [ 2.6, 1 ], [ 3.2, 1 ], [ 4.4, 0 ] ], u), y = p * 40;
    const LINES = [ MotionLocale.text("copy_080"), MotionLocale.text("copy_078"), MotionLocale.text("copy_079") ], F = `800 27px ${FONT}`;
    const total = LINES.join("").length;
    view(k, () => {
      k.save();
      k.translate(0, -y);
      txt(k, MotionLocale.text("ABOUT US"), 40, 34, `800 11px ${EN}`, C.acc, "left", "alphabetic", "2px");
      let n = 0;
      LINES.forEach((s, li) => {
        let x = 40;
        k.font = F;
        for (const ch of s) {
          const f = clamp(p * (total + 2) - n);
          txt(k, ch, x, 72 + li * 38, F, mix("#D6DBE4", C.ink, f));
          k.font = F;
          x += k.measureText(ch).width;
          n++;
        }
      });
      bars(k, 40, 168, 300, 3, C.faint, 6, 12, .7);
      k.restore();
      sbar(k, p, .55);
    });
  };
