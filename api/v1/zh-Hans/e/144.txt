Motion Prompt #144 · 分屏
一个全屏场景分成两个、再分成三个面板，每个面板内都有独立运动的场景。

- 全屏海景在 0.45–0.95 s 分成两个面板（分割线从 539→269.5），1.4–1.9 s 分成三个（分割线位于 1/3 和 2/3），3.75–4.4 s 合并回一个；均采用三次缓入缓出。
- 三个场景（海洋、城市、田野）分别在自己的面板中居中并裁切，内部持续运动：波浪和帆船、城市窗户每 4.7 s 切换 8 次、风车每 4.7 s 转两圈。
- 面板之间为线宽 6 的白色分割线。

Canvas: 539×208; cycle: 4.7s.

  // @element 24
    CELLS[23] = (k, w, h, u) => {
    u = snapU(u);
    const s2 = eIO(P(u, .45, .95)), s3 = eIO(P(u, 1.4, 1.9)), m = eIO(P(u, 3.75, 4.4));
    let b1 = lerp(lerp(w, w / 2, s2), w / 3, s3), b2 = lerp(w, 2 * w / 3, s3);
    b1 = lerp(b1, w, m);
    b2 = lerp(b2, w, m);
    pnSea(k, 0, b1, h, u, false);
    if (b1 < w - .5) pnCity(k, b1, Math.max(b1, b2), h, u, false);
    if (b2 < w - .5) pnField(k, b2, w, h, u, false);
    k.fillStyle = "#fff";
    [ b1, b2 ].forEach(b => {
      if (b < w - .5) k.fillRect(b - 3, 0, 6, h);
    });
  };
