Motion Prompt #122 · 跟随动作
圆形角色滑入后突然停止，头顶旗帜和尾巴继续摆动，随后逐渐停稳。

- 每 2.35 s 移动一次，每 4.7 s 两次，方向交替。身体为半径 38 的薄荷绿圆形，在 0.15–0.85 s 移动 303 px；前 30% 时间加速，之后匀速，在 0.85 s 突然停止。
- 旗帜由 58 px 白色旗杆和黄色旗面组成；角度使用由身体加速度推动的弹簧：a″ = −121a − 5.5a′ − 0.0175 × 加速度，固有频率 11 rad/s。旗布在旗杆角度基础上额外弯曲 0.6 倍。
- 尾巴由七段 14 px 的节段组成，珊瑚色，宽度 14→6；使用较慢的弹簧 b″ = −56b − 2.8b′ − 0.012 × 加速度。第 j 节采用 j × 22/600 s（约 j × 0.037 s）前的值，再乘以 (0.55 + 0.16j)。
- 两个弹簧均以 1/600 s 步长预计算；绘制时仅查找数值。
- 每次移动的最后 0.3 s，用 smoothstep 将摆幅渐变为 0，使循环无缝衔接。

    const FTAB = (() => {
    const T = CYC / 2, dt = 1 / 600, N = Math.ceil(T / dt) + 2, D = CW - 2 * 118;
    const pos = lu => {
      const q = P(lu, .15, .85), c = 1 / .85;
      return (q < .3 ? q * q / .6 : .15 + (q - .3)) * c;
    };
    const A = new Float32Array(N), B = new Float32Array(N);
    let a = 0, va = 0, b = 0, vb = 0, xp = 0, vp = 0;
    for (let i = 0; i < N; i++) {
      const lu = i * dt, x = pos(lu) * D, v = (x - xp) / dt, acc = i ? (v - vp) / dt : 0;
      xp = x;
      vp = v;
      va += (-121 * a - 5.5 * va - acc * .0175) * dt;
      a += va * dt;
      vb += (-56 * b - 2.8 * vb - acc * .012) * dt;
      b += vb * dt;
      const fade = 1 - smooth(P(lu, T - .3, T));
      A[i] = a * fade;
      B[i] = b * fade;
    }
    return {
      A: A,
      B: B,
      pos: pos,
      D: D
    };
  })();
