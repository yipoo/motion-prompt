Motion Prompt #137 · 推入转场
下一场景从侧面滑入，同时将当前场景推出画面。

- 海景→山景→海景，每段 2.35 s。每半段的 0.45–1.6 s 进行切换（持续 1.15 s），三次缓入缓出。
- 两幅场景始终相接，共同移动整个画面宽度（539 px），不重叠、不淡化。
- 方向：海景→山景向左移动（新场景从右侧进入）；山景→海景向右移动。
- 两场景的接缝用线宽 6 的藏青色线标记。

Canvas: 539×208; cycle: 4.7s.

  // @element 17
    const SC17 = [ scSea, scMtn ];
  CELLS[16] = abCell((k, w, h, u, a, b) => {
    const p = eIO(P(u, TA - .05, TB + .1)), dir = a === 0 ? -1 : 1;
    if (p <= 0) return SC17[a](k, w, h);
    if (p >= 1) return SC17[b](k, w, h);
    k.save();
    k.translate(dir * p * w, 0);
    SC17[a](k, w, h);
    k.restore();
    k.save();
    k.translate(dir * (p - 1) * w, 0);
    SC17[b](k, w, h);
    k.restore();
    const ex = dir < 0 ? w * (1 - p) : w * p;
    k.fillStyle = C.navy;
    k.fillRect(ex - 3, 0, 6, h);
  });
