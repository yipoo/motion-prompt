Motion Prompt #260 · 文字切片
文字上下两半沿相反方向滑动。

- 539×208 px Canvas 2D 卡片，4.8 s 确定性无缝循环。除特别说明外 q=(1−cos(2πt/4.8))/2。
- 使用 54 px 标题，以 y=104 居中；分别裁切 y=104 上方与下方。
- 上半部为蓝色，移动 −80q px；下半部为橙色，移动 +80q px。

Canvas: 539×208; cycle: 4.8s.

  // @element 20
  CELLS[19]=wrap((k,p)=>{let q=wave(p);for(let j=0;j<2;j++){k.save();k.beginPath();k.rect(40,j?104:20,459,j?84:84);k.clip();text(k,'SPLIT TYPE','文字切片',269+(j?1:-1)*80*q,104,54,j?C.orange:C.blue);k.restore();}});
