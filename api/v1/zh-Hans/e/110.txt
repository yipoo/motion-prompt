Motion Prompt #110 · 鱼眼镜头
街景中央向外鼓起，建筑竖线和道路线条向外弯曲，四角保持原位。

- 场景 2：街角；y 132–162 的道路后方有建筑、树木和路灯（x 114、292、494）；人物站在左前方，双脚位于 x 176、y 200，身高 124 px。
- 畸变：距中心为 d 的点，其距离乘以 g = (1 + k) / (1 + k·d²/R²)，其中 R 为中心至角落的距离，289 px。
- k 从 0→1.25；中央放大 2.25 倍，四角不移动。
- 所有轮廓在畸变前每 6 px 分段，使直线变成曲线。
- 右上角焦距 24mm→8mm。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

  // @element 14
    CELLS[13] = cell((k, u) => {
    const a = env(u), kk = 1.25 * a, cx = CW / 2, cy = CH / 2, R2 = cx * cx + cy * cy;
    const M = kk < .002 ? null : (x, y) => {
      const dx = x - cx, dy = y - cy, g = (1 + kk) / (1 + kk * (dx * dx + dy * dy) / R2);
      return [ cx + dx * g, cy + dy * g ];
    };
    stageStreet(k, BASE, {
      M: M
    });
    hud(k, `${Math.round(lerp(24, 8, a))}mm`);
  });
