Motion Prompt #106 · 移轴效果
街景顶部和底部变模糊，只有道路、汽车和小人物所在的中间区域保持清晰，使街道像一座模型。

- 街角场景：y 132–162 的道路后方有建筑、树木和路灯，没有大人物；四个身高 23–26 px 的小人物站在人行道上，双脚 y 172；汽车每 5 s 从 x −60 行驶至 600。
- 对焦带：y 66–176 保持清晰。
- 模糊度：y 0–42 和 y 190–208 从 0→7 px；y 42–66 和 y 176–190 从 0→3 px。
- 对焦带边缘有虚线，每段长 6 px、间隙 5 px，颜色 #8E8E93、不透明度 75%。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

  // @element 10
    CELLS[9] = cell((k, u) => {
    const a = env(u), carX = lerp(-60, 600, u / CYC);
    const minis = D => {
      [ [ 196, 26 ], [ 322, 26 ], [ 340, 23 ], [ 452, 25 ] ].forEach(([x, h]) => figure(D, x, 172, h, BASE.person));
    };
    const [S, ks] = layer("tilt");
    stageStreet(ks, BASE, {
      car: carX,
      person: false,
      after: minis
    });
    const [B1, k1] = layer("tilt-1");
    k1.filter = `blur(${(3 * a).toFixed(2)}px)`;
    k1.drawImage(S, 0, 0);
    k1.filter = "none";
    const [B2, k2] = layer("tilt-2");
    k2.filter = `blur(${(7 * a).toFixed(2)}px)`;
    k2.drawImage(S, 0, 0);
    k2.filter = "none";
    k.drawImage(S, 0, 0);
    const band = (img, y0, y1) => {
      k.save();
      k.beginPath();
      k.rect(0, y0, CW, y1 - y0);
      k.clip();
      k.drawImage(img, 0, 0);
      k.restore();
    };
    band(B2, 0, 42);
    band(B1, 42, 66);
    band(B1, 176, 190);
    band(B2, 190, CH);
    k.save();
    k.globalAlpha = .75 * a;
    k.strokeStyle = "#8E8E93";
    k.lineWidth = 1.4;
    k.setLineDash([ 6, 5 ]);
    k.beginPath();
    k.moveTo(0, 66);
    k.lineTo(CW, 66);
    k.moveTo(0, 176);
    k.lineTo(CW, 176);
    k.stroke();
    k.setLineDash([]);
    k.restore();
  });
