请实现「长曝光」（Long exposure），Motion Prompt #107。

效果说明：街道变为夜景；行驶的汽车几乎隐去，红色尾灯光线在车后拉长，对向车道出现白色与琥珀色线条。

动效规格：
- 场景 2：街角；y 132–162 的道路后方有建筑、树木和路灯（x 114、292、494）；人物站在左前方，双脚位于 x 176、y 200，身高 124 px。配色转为夜景，天空 #2C3B5E，每三个窗户中一个为 #FFC75A。
- 汽车每 5 s 从 x −60→600；车身不透明度 100%→10%。
- 尾灯线从 x −60 延伸到汽车位置：y 145 处为 #FF5B4D、粗 2.6 px，y 149 处为 #FF8A6E、粗 1.4 px。
- 对向车道的线条横贯全宽：y 135 处 #FFE9B8、粗 2.6 px；y 138.5 处 #FFC75A、粗 1.6 px；y 141.5 处 #FFE9B8、粗 1.2 px；随效果淡入。
- 右上角快门速度 1/250→8″。
- 时序：效果在 0.4–1.4 s 渐入，保持到 4.0 s，并在 4.8 s 前消失；每轮 5 s，使用 cubic ease-in-out，约为 cubic-bezier(0.65,0,0.35,1)。

适用场景：用于在单张静态图中表现车流，或丝绸般的流水与云彩。

语言：简体中文。演示中的文字也要使用中文，例如 GO! 显示为“出发！”。对于穿越缩放，中文标题放在圆环上方，保留圆环孔洞与缩放锚点。中文字体使用随项目提供的 assets/fonts/NotoSansSC.woff2（Motion Sans），不得依赖设备预装字体或远程字体。
画布：539 × 208 px；循环：5 秒。保持参考实现的图形、时长和缓动参数，仅根据需求调整文字、色彩和素材。支持响应式布局和 prefers-reduced-motion。
