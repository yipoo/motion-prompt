请实现「音量弹性边界」（Elastic volume feedback），Motion Prompt #319。

效果说明：滑块接近上界时轨道拉伸并压扁。 画布为确定性动效演示，未接入真实业务控件。

动效规格：
- 轨道为 216×38px，滑块以 2400ms 周期移动，最后 15% 区间映射至 18px 延伸和 4.5px 高度压缩。
- 参考画布为 539×208 CSS 像素，预览总周期 4800ms；其他尺寸保持等比缩放。
- 拖动时间轴时使用确定性运动。减少动态时保留稳定关键帧，保证标签可读，不仅依赖颜色表达状态。

适用场景：用于局部界面反馈；完整 Agent 交互组件参见 ADP。

语言：简体中文。演示中的文字也要使用中文，例如 GO! 显示为“出发！”。对于穿越缩放，中文标题放在圆环上方，保留圆环孔洞与缩放锚点。中文字体使用随项目提供的 assets/fonts/NotoSansSC.woff2（Motion Sans），不得依赖设备预装字体或远程字体。
画布：539 × 208 px；循环：4.8 秒。保持参考实现的图形、时长和缓动参数，仅根据需求调整文字、色彩和素材。支持响应式布局和 prefers-reduced-motion。
