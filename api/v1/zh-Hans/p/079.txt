请实现「滚动进度条」（Scroll progress bar），Motion Prompt #079。

效果说明：文章逐段阅读时，顶部横线从左侧不断增长，到达页面底部时延伸至最右端。

动效规格：
- 文章分四次、每次 110 px 从 0 滚到 430 px；每次移动 0.45 s 后停顿 0.4 s（cubic ease-in-out）。
- 3.75–4.55 s 从 430→0 返回。
- 视口顶部有一条 6 px 高的进度条：浅灰色轨道、橙色填充。
- 填充宽度 = 511 px × 滚动量 / 430，直接等于滚动进度比例，与 CSS animation-timeline: scroll() 相同。

适用场景：用于长文章，显示还剩多少内容未读。

语言：简体中文。演示中的文字也要使用中文，例如 GO! 显示为“出发！”。对于穿越缩放，中文标题放在圆环上方，保留圆环孔洞与缩放锚点。中文字体使用随项目提供的 assets/fonts/NotoSansSC.woff2（Motion Sans），不得依赖设备预装字体或远程字体。
画布：539 × 208 px；循环：4.8 秒。保持参考实现的图形、时长和缓动参数，仅根据需求调整文字、色彩和素材。支持响应式布局和 prefers-reduced-motion。

规格与代码：https://yipoo.github.io/motion-prompt/api/v1/zh-Hans/e/079.txt
共享辅助代码：https://yipoo.github.io/motion-prompt/api/v1/kit/lp.js

验收：以相同时间点比较关键帧；验证文字、时序和循环；检查中文字体加载与移动端显示。
