请实现「交叉剪辑」（Cross-cutting），Motion Prompt #190。

效果说明：同时发生的两个场景——跑步人物与汽车——交替出现，镜头越来越短。

动效规格：
- 两个场景共用同一时钟：A 为跑步人物，位于左侧 0.3 m，纵深 15→4.5 m，腿部运动为 u×12；B 为城中汽车，位于右侧 1 m，纵深 17→4.5 m；两者均在 4.7 s 内靠近相机。
- 剪切：在 0 / 1.1 / 2.0 / 2.7 / 3.3 / 3.8 / 4.2 / 4.5 s，于 A、B 之间直接切换；镜头时长从 1.1→0.9→0.7→0.6→0.5→0.4→0.3 s 逐渐缩短，以提升紧张感。
- 一个场景显示时，另一个场景仍继续推进，再次切回时主体已经前进。
- 相机：A 高度 1.3 m、固定，前景有四根柱子；B 高度 1.6 m、俯仰角 +0.06 rad、固定，画面中有城市和太阳。
- 底部条带：八段交替的 A（灰色）与 B（蓝色），带播放头；最后 0.3 s 交叉淡化回 A 的起始状态。
- 右上角显示 SCENE A / SCENE B。

适用场景：用于追逐、救援等同时发生的事件，增强紧张感。

语言：简体中文。演示中的文字也要使用中文，例如 GO! 显示为“出发！”。对于穿越缩放，中文标题放在圆环上方，保留圆环孔洞与缩放锚点。中文字体使用随项目提供的 assets/fonts/NotoSansSC.woff2（Motion Sans），不得依赖设备预装字体或远程字体。
画布：539 × 208 px；循环：9.4 秒。保持参考实现的图形、时长和缓动参数，仅根据需求调整文字、色彩和素材。支持响应式布局和 prefers-reduced-motion。
