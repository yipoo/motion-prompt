请实现「实时数据流」（Live data stream），Motion Prompt #240。

效果说明：双频波形持续横向流动，实时读数同步变化。

- 81 个采样点，横向步长 5.6 px；y = 122 + 30sin(a) + 15sin(2a)，a = i/12 + 2u。
- 末端珊瑚色点半径 6 px；实时读数为 round(120 + 30sin(2u))，整个周期持续更新。
- 画布 539×208，周期 4.8 秒；全部内容在 0–0.2 秒淡入、4.5–4.8 秒淡出，首尾为同一背景。

适用场景：演示实时监控、传感器或事件流。
