请实现「遮罩转场」（Mask transition），Motion Prompt #017。

效果说明：圆形或星形窗口逐渐扩大，在内部显露下一个场景。

动效规格：
- 白天场景 → 夜晚场景 → 白天场景，每段 2.35 秒。每半段的 0.45–1.6 秒进行切换（1.15 秒），使用三次方缓入缓出。
- 下一场景绘制在当前场景上方，裁剪为一个形状；形状不断扩大，直到覆盖整个画面。
- 白天→夜晚：以太阳中心（112, 104）为起点，圆形半径从 0 扩大至 470。
- 夜晚→白天：以月亮中心（427, 104）为起点，五角星外半径从 0 扩大至 1150，扩大时旋转 1.2 rad（约 69°）。
- 扩大过程中，形状边缘有白色描边（宽 7）。

适用场景：适合从画面中的太阳、标志或按钮等物体出发切换场景。

语言：简体中文。演示中的文字也要使用中文，例如 GO! 显示为“出发！”。对于穿越缩放，中文标题放在圆环上方，保留圆环孔洞与缩放锚点。中文字体使用随项目提供的 assets/fonts/NotoSansSC.woff2（Motion Sans），不得依赖设备预装字体或远程字体。
画布：539 × 208 px；循环：4.7 秒。保持参考实现的图形、时长和缓动参数，仅根据需求调整文字、色彩和素材。支持响应式布局和 prefers-reduced-motion。

验收：以相同时间点比较关键帧；验证文字、时序和循环；检查中文字体加载与移动端显示。
