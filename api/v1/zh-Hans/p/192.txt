请实现「蒙太奇」（Montage），Motion Prompt #192。

效果说明：七个短镜头展现三十天的训练，通过直接剪切衔接，右上角日期不断跳跃。

动效规格：
- 七个镜头通过直接剪切衔接，过渡为 0 帧，时长依次为 0.75 / 0.7 / 0.65 / 0.65 / 0.65 / 0.6 / 0.7 s，总计 4.7 s；右上角日期跳为 DAY 1→3→7→12→20→28→30。
- 镜头：1 跟拍跑步者，腿部运动为 t×14；2 公园跳跃；3 日出，太阳高度从 4→12 m；4 低角度拍摄双臂举起；5 城中行走，焦距 420 px；6 绕人物从 −0.3→+0.3 rad 转动；7 在旗帜前举起双臂。
- 将三十天训练压缩为 4.7 s，每个镜头的相机位置、高度与焦距均有变化（#041 Jump cut 保持相同构图）。
- 底部条带分为七段，仅当前镜头为蓝色；最后 0.3 s 交叉淡化回第一个镜头的起始状态。

适用场景：用于在短时间内展现长期变化或努力。

语言：简体中文。演示中的文字也要使用中文，例如 GO! 显示为“出发！”。对于穿越缩放，中文标题放在圆环上方，保留圆环孔洞与缩放锚点。中文字体使用随项目提供的 assets/fonts/NotoSansSC.woff2（Motion Sans），不得依赖设备预装字体或远程字体。
画布：539 × 208 px；循环：9.4 秒。保持参考实现的图形、时长和缓动参数，仅根据需求调整文字、色彩和素材。支持响应式布局和 prefers-reduced-motion。
