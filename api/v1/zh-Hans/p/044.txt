请实现「交叉溶解」（Cross dissolve），Motion Prompt #044。

效果说明：下一幅画面叠在当前画面上，不透明度逐渐提高直至完全替代；中途两幅画面相互透出。

动效规格：
- 剪接：1.5–3.0 秒，共 1.5 秒；下一幅画面的不透明度从 0 增至 100%。
- 缓动：二次方缓入缓出（约 cubic-bezier(0.45,0,0.55,1)）；2.25 秒时为 50%。
- 前一幅画面在底下始终完全不透明，后一幅绘制在上方（不会先将前一幅淡出）。
- 相机：两幅画面均固定（A 高 1.4 m；B 高 1.6 m，俯仰角 +0.1 rad）；主体也不动。
- 0–1.5 秒只显示前一幅画面，3.0–4.7 秒只显示后一幅。
- 每 4.7 秒交替进行 A→B 与 B→A（往返 9.4 秒）；右上角显示“A → B” / “B → A”。

适用场景：适合表达柔和的时间流逝、地点变化，或进入回忆。

语言：简体中文。演示中的文字也要使用中文，例如 GO! 显示为“出发！”。对于穿越缩放，中文标题放在圆环上方，保留圆环孔洞与缩放锚点。中文字体使用随项目提供的 assets/fonts/NotoSansSC.woff2（Motion Sans），不得依赖设备预装字体或远程字体。
画布：539 × 208 px；循环：9.4 秒。保持参考实现的图形、时长和缓动参数，仅根据需求调整文字、色彩和素材。支持响应式布局和 prefers-reduced-motion。
